# Сравнение способов параллельной обработки изображений

Учебная работа на C++: последовательная обработка PNG сравнивается с OpenMP, SIMD и OpenCL. Реализации находятся в `sequential.cpp`, `openmp.cpp`, `simd.cpp` и `opencl.cpp`.

## Запуск

Нужен C++-компилятор; для отдельных вариантов — поддержка OpenMP, SIMD-инструкций процессора или OpenCL SDK и драйвер устройства. Параметры командной строки описаны в функции printUsage каждого файла. Пример сборки последовательного варианта в MSVC: `cl /EHsc /std:c++17 sequential.cpp /Fe:sequential.exe`.

В репозитории сохранены входные изображения, результаты учебных запусков и отчёт. Готовые исполняемые файлы и промежуточные объектные файлы не нужны для сборки из исходников.

## Ограничения измерений

Результаты зависят от устройства, компилятора, размера изображений и затрат на передачу данных. Сравнивать ускорение следует при одинаковом результате обработки, с повторными замерами и отдельным учётом ввода/вывода. Сохранённый отчёт не доказывает ускорение на другой машине.
